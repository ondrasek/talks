# talks

Slide decks for talks by [Ondrej Krajicek](https://www.linkedin.com/in/OndrejKrajicek).

**Published site: <https://ondrasek.github.io/talks/>**

Each talk lives in its own `YYYY-MM-DD-slug/` directory as a self-contained
[reveal.js](https://revealjs.com/) deck that installs as a PWA and runs offline
once opened, alongside PDF exports of the slides and the audience handout.

## How this repository is written

Nothing here is edited by hand. Decks are generated from a private notes vault
and pushed by an automated pipeline; this repository is the publication target
only. A talk appears here only after it passes a grounding gate — every factual
claim on a slide traces to a numbered source entry or is explicitly marked as
the author's own reasoning.

Slide sources, speaker notes and the evidence registry stay in the private
vault. What is published is the render.
